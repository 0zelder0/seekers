Seekers admin

Sign in to change the website's pictures, text, fees and news.

Your GitHub username, a slash, then the repository name. Example: seekers-bd/seekers-site

How do I get an access token?
  1. Sign in to GitHub, click your picture, then Settings.
  2. Scroll down the left side to Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Press Generate new token. Name it Seekers admin and set the longest expiry offered.
  4. Under Repository access, choose Only select repositories and pick your website repository.
  5. Under Repository permissions, set Contents to Read and write.
  6. Press Generate token and copy it. GitHub shows it only once, so save it somewhere private.

The token works only for this one repository. Anyone who has it can change your site, so do not share it.
