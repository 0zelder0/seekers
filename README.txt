SEEKERS WEBSITE + ADMIN PANEL

Files
  index.html        the website
  content.json      what the admin panel saves (text, picture links, fees, news, gallery)
  uploads/          pictures you add are saved here
  admin/index.html  the admin panel, at  your-site-address/admin/

Put it online
  1. Open your GitHub repository, press Add file > Upload files.
  2. Drag in everything from this folder (index.html, content.json, admin, uploads, .nojekyll).
     If the repository already has an old index.html, this replaces it.
  3. Press Commit changes. Wait a minute.
  4. Open  https://YOUR-NAME.github.io/YOUR-REPOSITORY/admin/

Sign in with  your-name/your-repository  and a fine-grained access token
(Contents: Read and write, this repository only). Steps are in the "How do I get an access token?" box on the sign-in page.
